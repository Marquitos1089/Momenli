# Momentitos

Testversion der Momentitos-App: alle Momente und Meilensteine eines Babys an einem Ort. Jeder Moment zählt.

Die App läuft komplett im Browser. Alle Einträge, Fotos, Videos und Sprachnachrichten bleiben auf dem jeweiligen Gerät und werden an keinen Server gesendet. Die angezeigten Beispieldaten sind erfunden.
